## 📝 Project Summary

Developed an end-to-end **E-Commerce Sales Analytics Dashboard** using Python, MySQL, Excel, and Power BI to analyze transactional sales data and uncover meaningful business insights. The project focused on transforming raw e-commerce order records into actionable intelligence to support revenue optimization, customer behavior understanding, and inventory planning strategies.

The dataset, sourced from Kaggle's E-Commerce Sales Transactions Dataset, contained information such as order IDs, product categories, customer details, transaction dates, quantities, pricing, and regional data. Raw data was cleaned and preprocessed using Python and Excel, then stored and queried efficiently in a MySQL relational database, and finally visualized through an interactive Power BI dashboard.

The system applied multiple analytical techniques including:

- Exploratory Data Analysis (EDA)
- Sales Trend & Revenue Analysis
- Customer Segmentation
- Product Performance Analysis
- Regional Sales Distribution
- KPI Reporting & Interactive Dashboard Design

By integrating database management, statistical analysis, and business intelligence reporting, the project successfully identified top-performing products, peak sales periods, customer purchasing patterns, and regional revenue concentration.

## 🧩 Key Analytical Modules Developed

### 🔍 Data Preprocessing & ETL Pipeline
- Cleaned missing values, duplicate records, and inconsistent entries using Python (Pandas)
- Standardized column formats including date parsing, category names, and numeric fields
- Transformed and exported cleaned data to MySQL database using SQLAlchemy
- Structured data into analysis-ready format in Excel for reporting

### 📊 Exploratory Data Analysis (EDA)
Analyzed sales performance across:
- Product categories and sub-categories
- Order date, month, and seasonal trends
- Customer demographics and regions
- Pricing, discount impact, and profit margins

Generated statistical summaries, correlation matrices, and trend reports using Python

### 📈 Sales Trend & Revenue Analysis
- Identified monthly, quarterly, and yearly revenue trends
- Detected peak sales periods and low-demand seasons
- Analyzed impact of discounts on overall profit
- Computed revenue contribution by product category

### 👥 Customer Segmentation Analysis
- Segmented customers based on purchase frequency, order value, and region
- Identified high-value and repeat customers
- Analyzed customer distribution across geographic regions

### 🏆 Product Performance Analysis
- Ranked top-selling products by revenue and quantity
- Identified low-performing and high-return products
- Analyzed category-wise profit margins and sales velocity

### 🗄️ MySQL Database Integration
- Designed and created relational database schema in MySQL
- Loaded cleaned transaction records using Python (SQLAlchemy / mysql-connector)
- Wrote SQL queries for aggregations, joins, and business metric extraction
- Used MySQL Workbench for query management and data validation

### 📉 Power BI Interactive Dashboard
Built a fully interactive Power BI dashboard featuring:
- Monthly & Yearly Revenue KPI Cards
- Sales Trend Line Charts
- Category-wise Bar and Donut Charts
- Regional Sales Map Visualization
- Top Products & Customer Tables
- Dynamic slicers for date, region, and category filtering

### 📋 Excel Reporting
- Created structured pivot tables and summary reports
- Designed formatted Excel sheets for stakeholder-ready reporting
- Used conditional formatting for quick performance insights

## 🛠️ How to Use

1. Download the dataset from Kaggle
2. Run the Python preprocessing script to clean and transform the data
3. Connect to MySQL and execute the schema creation script
4. Load cleaned data into MySQL
5. Install required Python libraries:
   - `pandas`
   - `openpyxl`
6. Open Power BI Desktop and connect to the MySQL data source
7. Load the `.pbix` dashboard file and refresh data
8. Use slicers and filters to explore sales insights interactively
